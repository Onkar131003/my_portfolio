Project Overview

Subhash Fitness Town Gym is a responsive gym class registration and scheduling web portal. It was built using HTML, CSS, JavaScript, Bootstrap, and PHP to ensure seamless performance and presentations of gym classes, timetables, and registration pages across all mobile and desktop devices.

The Problem

Traditional gym registration processes rely on offline registries, manual tracking, and face-to-face updates. Members frequently face scheduling conflicts and overbooked slots. This portal was built to unify registration and scheduling into a single, real-time online experience.

Key Features

Membership Registration

Online member registration form capturing applicant profiles securely.

Timetables & Schedules

Interactive training logs, slot selections, and trainer programs display.

Trainer Profiles

Displays trainer bios, certifications, and slot details dynamically.

Engineering Challenges

Challenge: Double booking of training slots during peak hours
Solution: Implemented strict database transaction checking and server-side validation in PHP before booking confirmation.
Challenge: Responsive timetable layouts on narrow screens
Solution: Developed fluid Bootstrap grid layouts combined with custom CSS media queries for overflow scrolling.
