HR Analytics

Predictive insights into workforce health and retention.

GitHub Repo
TimelineAug 2025 - Aug 2025
RoleData Analyst & Engineer

Executive Summary

Overview: A sophisticated analytics solution focused on human resource metrics. It provides leadership with a strategic overview of employee satisfaction, attrition risks, and diversity metrics through interactive visualizations.

The Problem

High employee turnover is costly. Organizations often realize employees are dissatisfied only after they resign. This tool was built to identify pre-resignation patterns and help HR take proactive retention measures.

Key Features

Attrition Predictor

Uses historical data to flag departments or roles with high flight risks.

Demographic Insights

Tracks diversity and inclusion metrics across the organizational hierarchy.

Performance vs. Pay Analysis

Identifies compensation anomalies.

Engineering Challenges & Solutions

Challenge

Handling sparse and inconsistent historical HR data

Solution

Implemented rigorous data cleaning pipelines in Python, utilizing mean imputation and SMOTE for balancing attrition classes.

Key Learnings

  • Deepened expertise in SQL window functions.
  • Learned best practices for designing Tableau dashboards tailored for executive audiences.

Future Roadmap

  • Incorporate real-time employee survey data via API.
  • Develop a natural language query interface for HR managers.
